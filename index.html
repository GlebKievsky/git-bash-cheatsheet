Как назвать коммит <тип>: <что изменилось> отвечает на «что изменилось», а не «что я делал»
так

  • fix: resolve crash on startup
  • Fix broken link in footer
  • Add user profile page
не так
  • fix
  • done
  • final version
  • asdf
